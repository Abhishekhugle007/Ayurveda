# Sanatan Ayurveda (Angular 18, TypeScript)

## Run
    npm install
    npm start          # http://localhost:4200
    npm run build      # output in dist/sanatan-ayurveda (upload this folder to your host)

## Edit
- `src/app/config.ts`   WhatsApp number, consult fee, concerns and time slots
- `src/app/products.ts` products, prices and images (photos live in `src/assets/img`)
- `src/app/app.component.html` page sections (hero, consult, doctor, clinic, hospital, history)
- `src/styles.css`      all styling
